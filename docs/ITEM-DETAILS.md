# 0.1.6 update

0.1.6 has 649 named icon mappings and 272 explicitly unavailable mappings. The earlier 225-entry mapping below remains historical, not full current coverage. New entries include action/facility descriptions, other skill requirements and per-row Wiki targets. All 921 sprites/pages have not been visually/HTTP checked.

# Item details and artwork — 0.1.2

Icons are RuneLite game-cache sprites. The named identifiers below were checked against [RuneLite game definitions](https://github.com/runelite/runelite/blob/runelite-parent-1.13.3/runelite-api/src/main/java/net/runelite/api/gameval/ItemID.java). They are construction/skill-guide icons, not screenshots of a placed object. Source titles and accessible indexed Wiki pages were used for descriptions and links. Some pages could not be fetched directly; URL targets are not all click-verified.

## Live acceptance

1. Search mahogany cargo hold; check name above the game icon.
2. Choose Raft, Skiff and Sloop; confirm 60, 90 and 120 slots. All boats shows all three.
3. Open Wiki source; confirm the individual cargo-hold page.
4. Switch rapidly between different recipes; confirm no stale image or description.
5. Select a house upgrade such as mahogany magic wardrobe; Include earlier upgrades should appear. Select a cargo hold; it should disappear.
6. Compare the actual game icons at your usual panel width. No live account/client was available to the build environment.
