# Feedback

Repository: https://github.com/jasondev92-ops/build-planner

The three issue forms live under `.github/ISSUE_TEMPLATE`: suggestions, bugs, and recipe corrections. The plugin's Info → Suggestions & bug reports button opens:
https://github.com/jasondev92-ops/build-planner/issues/new/choose

A player signs into GitHub and submits the form manually. The plugin does not send messages or upload account data, screenshots or logs. Avoid including credentials or private account information in public reports.

The link is configured in `src/main/resources/com/buildplanner/release.properties`. Change it only if the repository moves, then rebuild. Issues must stay enabled in the repository settings.
