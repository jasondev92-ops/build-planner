# Description sources — 0.1.9

Original summaries checked against OSRS Wiki item and room documentation on 16 November 2026. Shared functions are described consistently across tiers and cosmetic variants. Each override retains its item source in `tools/recipe-descriptions.json`; existing specific descriptions and numeric stats are retained. These summaries are bundled; the plugin makes no new Wiki requests at runtime.

Review included functional furniture, decorative room families, workshop tools, heraldry, teleport furniture, games, pets, ship parts, island amenities and world construction activities. Key distinctions include the functional spirit tree versus decorative garden trees, the mythical cape teleport versus the decorative mounted legends cape, and manually supplied game ammunition. This is a description pass, not a fresh re-audit of every numeric game statistic.
